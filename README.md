# 机场订阅流量小组件（doufu 改版）

基于 [Aswoth/Keek](https://github.com/Aswoth/Keek) 的机场订阅流量监控小组件修改，针对 Egern 中号小组件优化。

## 改版内容

- 🐭 进度条上加了一只皮卡丘，站在流量用量对应的位置（跑到哪里 = 用到哪里）
- 🎨 深色模式用蓝色动漫背景、浅色模式用粉色动漫背景（图片内嵌在脚本里，随模块自动更新）
- 其余逻辑（订阅抓取、环境变量、4 小时刷新）保持原版不变

## 使用方法

### 1. 添加脚本

Egern → 工具 → 脚本 → `+`，新建一个 **generic** 类型脚本：

- 名称：`airport`（任意）
- 文件位置：远程，填入

```
https://raw.githubusercontent.com/James-bot2/doufu-airport/main/airport.js
```

### 2. 创建小组件

Egern 底部「分析」→ 左上角进入小组件画廊 → `+`，脚本选择上一步的 `airport`，尺寸选**中号**。

### 3. 配置环境变量

在小组件（或脚本）的 **Env** 中添加（名称必须大写）：

| 变量 | 说明 | 示例 |
|------|------|------|
| `NAME1` | 机场名称，显示在卡片上 | `翻墙` |
| `URL1` | 订阅地址，从机场后台复制（必填，含完整 token） | `https://example.com/sub?token=abc123` |
| `RESET1` | 流量重置日，1–28 的数字（可选） | `1` |

最多支持 5 个机场（`NAME1-5` / `URL1-5` / `RESET1-5`），至少配置 `URL1` 才能显示。

### 4. 添加到主屏幕

长按主屏幕 → `+` → 搜索 Egern → 选中号小组件 → 长按小组件 → 编辑小组件 → 选择 `airport`。

## 注意事项

- 订阅地址只保存在你手机 Egern 本地，不会上传到任何地方
- 小组件每 4 小时自动刷新
- 深色/浅色模式自动切换对应背景（如果背景没有跟随系统切换，跟我说一声）
- 3 个机场以内显示效果最佳
